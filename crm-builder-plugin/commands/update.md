description: Capitaliser les apprentissages du projet courant dans la skill crm-builder
---
Exécute le protocole de mise à jour de la skill décrit dans skills/crm-builder/references/maintenance-skill.md :
1. Lis HANDOFF.md et CRM_STATE.md du projet courant (et tout doc fourni)
2. Extrais uniquement les patterns généralisables (test : utile pour un autre métier/entreprise ?)
3. Classe-les dans les bons fichiers de références du plugin (dépôt crm-builder-plugin)
4. Mets à jour les fichiers, ajoute la date en bas de chaque fichier modifié
5. Résume : patterns ajoutés, fichiers modifiés, éléments écartés et pourquoi
6. Rappelle à l'utilisateur de commit/push le dépôt du plugin puis de mettre à jour le plugin
