# crm-builder — Plugin Claude Code

Méthode réutilisable pour construire des CRM et outils de pilotage commercial,
quel que soit le métier, l'entreprise ou la base de données.

## Installation (Claude Code)

```
/plugin marketplace add echampalou-bit/crm-builder-plugin
/plugin install crm-builder@crm-builder-marketplace
```

## Mise à jour

Après un push sur ce dépôt :
```
/plugin marketplace update crm-builder-marketplace
```

## Commandes

- `/crm-builder:new` — démarrer un nouveau CRM (cadrage complet)
- `/crm-builder:update` — capitaliser les apprentissages d'un projet dans la skill
- `/crm-builder:deploy` — checklist de déploiement guidée

## Contenu

La skill `crm-builder` : workflow en 8 étapes + 10 fichiers de référence
(schéma Supabase canonique, architecture Next.js, format HTML léger, sync externe,
extraction de contacts, KPIs, déploiement, workflow projet, modules IA, maintenance).
