# Plan Performance — Année 2

> Synthèse du process de suivi post-Plan BOOSTÉ (M12 → M24).
> Source : page Notion "Plan Performance — Année 2"
> Dernière synchronisation : avril 2026

## Principe

Méthode générique applicable à toute agence Aeconomia ayant terminé son Plan BOOSTÉ (M12).
Prend le relais du Plan BOOSTÉ à **M12** et couvre les **12 mois suivants** (M12 → M24).
Objectif : amener l'agence à son **niveau Croisière** via un pilotage trimestriel structuré.

**1 plan co-construit à M12. 1 cadence trimestrielle. 1 journée de co-pilotage par trimestre.**

## Articulation avec le lifecycle agence

| Période | Plan | Objectif | Cadence |
|---|---|---|---|
| **M0 → M12** | Plan BOOSTÉ | Lancer l'agence, prouver le modèle | Hebdo → bimensuel → mensuel → trimestriel |
| **M12** | Transition | Bilan Y1 + co-construction Plan Performance | Revue SMART M12 (tripartite) |
| **M12 → M24** | **Plan Performance** | Atteindre le niveau Croisière | **Trimestriel — Journée de co-pilotage** |
| **M24+** | Standard Croisière | Maintenir le cap | Co-pilotage trimestriel ou semestriel |

## Préparation à M12 — Co-construction du Plan Performance

Même rituel que la co-construction du Plan BOOSTÉ à J15 : chacun fait son travail, on confronte.

### Le Directeur — bilan + proposition
- Bilan factuel Y1 : les 12 indicateurs Plan BOOSTÉ à M12 (réel vs objectif)
- Auto-diagnostic : ce qui a fonctionné, ce qui a manqué, les leçons
- Proposition d'objectifs M18 / M24 sur les 3 blocs KPI
- Vision équipe : effectif actuel, besoins de recrutement, dynamique

### La Direction — cadre cible + benchmark
- Standards de performance : les seuils Croisière pour le type d'entité (Studio / Maison)
- Benchmark réseau : comparaison avec les autres agences à M12
- Deux scénarios : plancher (minimum Croisière) et cible (Excellence)

### Revue tripartite M12
1. Le Directeur présente son bilan Y1 et ses objectifs Y2
2. La Direction challenge avec le cadre Standards + benchmark
3. Ajustement à 3, calibration, validation
4. Signature tripartite du Plan Performance = engagement Y2

## Journée de co-pilotage — Format unique

Voir `references/journee-copilotage.md` pour le format détaillé.

**Matin (9h → 12h) — Équipe + Directeur** : Restitution Baromètre (30 min), Revue KPI (30 min), Atelier collectif (45 min), Engagements collectifs (15 min).

**Déjeuner (12h30 → 14h)** : Directeur + Direction, débrief informel.

**Après-midi (14h → 16h) — Directeur seul** : Lecture stratégique Baromètre (30 min), Analyse écarts Plan Performance (30 min), Entretien de vérité (20 min), Engagements mutuels (10 min).

## Lien avec le Plan de progression Directeur

La journée de co-pilotage alimente les 3 blocs du scoring directeur :

| Bloc | Points | Ce qui est évalué | Source dans la journée |
|---|---|---|---|
| A. Compétences | 150 pts | Leadership, pilotage, organisation | Blocs 5-6-7-8 (après-midi) |
| B. Baromètre Équipe | 100 pts | Qualité managériale perçue | Bloc 1 (matin) — score /5 × 20 |
| C. Niveau Agence | 150 pts | KPI + avis clients | Bloc 2 (matin) — 12 indicateurs |
| Discrétionnaire | ±20 pts | Appréciation Direction | Impression globale de la journée |
